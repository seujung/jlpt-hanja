# JLPT 상용한자 2136 학습 웹앱

해커스 일본어 『일차별 상용한자 2136』 암기장을 기반으로 만든 웹 학습 도구입니다.
일차별 **토리파 암기법(7단계)**, **발음 듣기(TTS)**, **복습 퀴즈**, **진도 백업/복원** 기능을 제공합니다. 화면 톤은 나인존 리포트(kbo-analytic-report)의 디자인 시스템을 따르며, 라이트 기본 + 시스템 다크 모드를 자동 지원합니다.

## 기능

- **토리파 암기법** — 30일차, 한자 2136자. 일차별로 `한자` / `예시·기출 단어` 두 세트를 7단계(체크 → 입으로 암기 → 더블체크 → 적기 → 노트 정리 → 6시간 후 복습 → 3일 뒤 복습)로 외웁니다. 안다/모른다는 **4지선다 문제**로 판정하며, 틀릴 때마다 ✔ → ✔✔ → ✔✔✔ 체크가 올라갑니다.
- **랜덤 순서** — 토리파 단계 목록의 `🔀 랜덤 순서` 버튼을 켜면 1~5단계를 시작할 때마다 항목 순서를 무작위로 섞습니다(끄면 한자 번호 순서, '이어서 하기'는 저장된 순서 유지, 6·7단계 복습은 항상 무작위).
- **레벨 필터** — 토리파는 JLPT 레벨(N5~N1)을 복수 선택해 그 일차 안에서 해당 레벨의 한자·단어만 학습할 수 있습니다(레벨 미표기 한자는 항상 포함, 예시 단어는 부모 한자 레벨 기준). 퀴즈는 관련 기출 단어의 레벨을 따로 선택합니다.
- **발음 듣기** — 각 단어의 `🔊` 버튼으로 일본어 발음을 들려줍니다(Web Speech API, 기본 여성 음성). 사이드바 하단에서 음성 선택 가능.
- **일차별 퀴즈** — 해당 일차의 한자·단어로 4지선다 문제를 자동 생성(뜻·음 / 읽기 / 단어 고르기). 틀린 문제 복습, 재응시마다 새로 섞임.
- **진도 저장 및 백업** — 토리파 진행 상태·체크, 퀴즈 최고 점수를 브라우저에 자동 저장하고, 사이드바에서 파일로 내보내기/불러오기 할 수 있습니다(v2 백업 파일도 불러올 수 있으며 구 카드 학습 진도는 무시됩니다).

## 로컬에서 실행

`index.html`을 브라우저에서 바로 열면 됩니다. (데이터가 `data/hanja.js`에 포함되어 별도 서버가 필요 없습니다.)

서버로 띄우고 싶으면:

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## GitHub Pages 배포와 접속 URL

이 폴더에서 아래 명령으로 저장소를 만들고 push 합니다.

```bash
cd /Users/digit82/repo/jlpt-hanja
rm -rf .git          # 준비 과정에서 생긴 빈 git 폴더 정리 (있을 때만)
git init
git add -A
git commit -m "JLPT 상용한자 2136 학습 웹앱"
git branch -M main
git remote add origin https://github.com/<사용자명>/jlpt-hanja.git
git push -u origin main
```

그다음 GitHub 저장소에서 Pages를 켭니다.

- **방법 A (브랜치 배포)**: 저장소 **Settings → Pages → Source** 를 `Deploy from a branch`, Branch 를 `main` / `/(root)` 로 지정 후 저장.

### 접속 주소(URL)

배포가 끝나면 아래 주소로 접속합니다. (1~2분 소요)

```
https://<사용자명>.github.io/jlpt-hanja/
```

- 예: 사용자명이 `hong` 이면 → `https://hong.github.io/jlpt-hanja/`
- 저장소 이름을 다르게 만들었다면 `jlpt-hanja` 자리에 그 이름을 넣으세요.
- 실제 주소는 저장소 **Settings → Pages** 상단에도 표시됩니다.

## 학습 진도는 어디에 저장되나요?

GitHub Pages는 **정적 호스팅**이라 서버에 사용자별 데이터를 저장하지 못합니다. 그래서 진도는 다음과 같이 관리됩니다.

1. **기본: 브라우저 저장(localStorage)** — 접속한 브라우저 안에 자동 저장됩니다. 같은 기기·같은 브라우저에서는 계속 이어집니다. 단, 브라우저 데이터를 지우거나 다른 기기·브라우저에서 열면 진도가 공유되지 않습니다.

2. **별도 위치 저장: 내보내기/불러오기(권장)** — 사이드바의 `⬇ 진도 내보내기` 로 진도를 JSON 파일로 저장할 수 있습니다. 이 파일을 원하는 곳(클라우드 드라이브, USB 등)에 두었다가, 다른 기기에서 `⬆ 진도 불러오기` 로 복원하면 됩니다. 불러올 때는 기존 진도와 **더 높은 값으로 병합**됩니다. (별도 서버 없이 완전히 동작하는 방식입니다.)

3. **자동 클라우드 동기화(선택, 추가 작업 필요)** — 여러 기기에서 자동으로 이어보고 싶다면, 클라이언트 자바스크립트에서 외부 백엔드를 호출해 저장할 수 있습니다. GitHub Pages(정적)만으로는 불가능하고, 무료로 붙일 수 있는 예로는 Firebase / Supabase(로그인+DB), 또는 GitHub Gist API 등이 있습니다. 필요하면 이 기능을 추가로 구현해 드릴 수 있습니다.
