# JLPT 상용한자 2136 학습 웹앱

해커스 일본어 『일차별 상용한자 2136』 암기장을 기반으로 만든 웹 학습 도구입니다.
일차별 **토리파 암기법(7단계)**, **발음 듣기(TTS)**, **복습 퀴즈**, **iCloud 진도 저장** 기능을 제공합니다. iPad·iPhone 홈 화면에 웹 앱으로 설치해서 씁니다. 화면 톤은 나인존 리포트(kbo-analytic-report)의 디자인 시스템을 따르며, 라이트 기본 + 시스템 다크 모드를 자동 지원합니다.

## 기능

- **토리파 암기법** — 30일차, 한자 2136자. 일차별로 `한자` / `예시·기출 단어` 두 세트를 7단계(체크 → 입으로 암기 → 더블체크 → 적기 → 노트 정리 → 6시간 후 복습 → 3일 뒤 복습)로 외웁니다. 안다/모른다는 **4지선다 문제**로 판정하며, 틀릴 때마다 ✔ → ✔✔ → ✔✔✔ 체크가 올라갑니다.
- **랜덤 순서** — 토리파 단계 목록의 `🔀 랜덤 순서` 버튼을 켜면 1~5단계를 시작할 때마다 항목 순서를 무작위로 섞습니다(끄면 한자 번호 순서, '이어서 하기'는 저장된 순서 유지, 6·7단계 복습은 항상 무작위).
- **레벨 필터** — 토리파는 JLPT 레벨(N5~N1)을 복수 선택해 그 일차 안에서 해당 레벨의 한자·단어만 학습할 수 있습니다(레벨 미표기 한자는 항상 포함, 예시 단어는 부모 한자 레벨 기준). 퀴즈는 관련 기출 단어의 레벨을 따로 선택합니다.
- **발음 듣기** — 각 단어의 `🔊` 버튼으로 일본어 발음을 들려줍니다(Web Speech API, 기본 여성 음성). 사이드바 하단에서 음성 선택 가능.
- **일차별 퀴즈** — 해당 일차의 한자·단어로 4지선다 문제를 자동 생성합니다(뜻·음 / 漢字読み / 表記). 틀린 문제 복습, 재응시마다 새로 섞임.
- **JLPT 시험식 함정 보기** — 漢字読み(읽기) 오답은 정답 읽기의 장음·촉음·탁음·요음을 바꿔 만듭니다(예: こくさい → こっさい·こぐさい). 表記(한자 표기) 오답은 한 글자를 음독이 같은 한자나 한국음이 같은 한자로 바꿔 만듭니다(예: 現代 → 玄代·源代). 같은 읽기의 실제 단어는 오답에서 뺍니다.
- **한국 한자음 힌트** — 정답 확인 화면에 한자별 한국음·음독·대응 규칙(ㅇ 받침 → 장음, ㄴ·ㅁ → ん, ㄱ → く·き, ㄹ → つ·ち, ㅂ → う)을 보여 줍니다. 규칙에 맞지 않는 한자는 "예외"로 표시합니다.
- **목표 레벨 · 시험일 계획** — 개요에서 목표 레벨(N5~N1)과 시험일(기본: 다음 7월·12월 첫째 일요일)을 정합니다. 앱은 D-day, 학습 범위(N5·N4: 1~6일차, N3·N2: 1~18일차, N1: 1~30일차), 하루 목표 일차, 오늘 할 일차를 계산합니다. 목표 레벨을 바꾸면 토리파·퀴즈 레벨 필터가 N5~목표 레벨로 맞춰집니다.
- **오늘의 복습(SRS)** — 토리파·퀴즈·모의 시험에서 틀린 단어가 복습 큐에 들어갑니다. 맞히면 간격이 1일 → 3일 → 7일 → 14일 → 30일로 늘어나고, 틀리면 10분 뒤에 다시 나옵니다.
- **모의 시험** — 목표 레벨 기출 단어로 문자 영역(漢字読み → 表記) 문제를 대략적인 실제 문항 수만큼 내고, 문제당 40초로 시간을 잽니다(N1은 表記 없음). 결과는 대문별 정답률과 걸린 함정 유형으로 보여 줍니다. 출제 범위는 목표 레벨 전체, 마당별, 일차별 중에서 고릅니다. 일차 화면의 `⏱ NN일차 모의 시험` 버튼으로 그 일차 범위의 시험을 바로 시작할 수도 있습니다.
- **오답 단원 표시** — 틀린 문제의 정답 화면과 결과 목록에 그 단어가 나오는 단원(일차·분류·한자)을 표시합니다. 결과 화면은 단원별 오답 수도 보여 줍니다. 단원 표시를 누르면 그 일차로 이동합니다. 文脈規定·言い換え類義·用法은 예문 데이터가 없어 다루지 않습니다.
- **진도 저장** — 토리파 진행 상태·체크, 퀴즈 최고 점수, 복습 큐, 함정 통계, 모의 시험 기록, 목표 레벨·시험일을 기기에 자동 저장합니다. 사이드바 "설정"에서 진도 파일을 iCloud Drive에 저장하고 불러옵니다(v2 이후 진도 파일을 모두 불러올 수 있습니다. 구 카드 학습 진도는 무시합니다).
- **홈 화면 앱** — 홈 화면에 추가하면 주소 표시줄 없이 전체 화면으로 열립니다. 한 번 연 뒤에는 인터넷이 없어도 열립니다.

## 홈 화면에 설치

주소는 https://seujung.github.io/jlpt-hanja/ 입니다.

### iPad·iPhone

1. Safari로 위 주소를 여십시오.
2. 공유 버튼을 누르고 "홈 화면에 추가"를 누르십시오.
3. 홈 화면의 "JLPT 한자" 아이콘으로 앱을 여십시오.

설치한 뒤에는 Safari 대신 홈 화면 아이콘으로 여십시오. 홈 화면 앱은 Safari와 진도를 따로 저장합니다.

### Android·데스크톱 Chrome

주소를 열고 메뉴의 "앱 설치"(또는 "홈 화면에 추가")를 누르십시오.

### 새 버전

앱은 인터넷에 연결되어 있으면 열 때마다 최신 파일을 받습니다. 연결이 없거나 3초 안에 응답이 없으면 저장해 둔 파일로 엽니다. 새 버전이 보이지 않으면 앱을 완전히 닫았다가 다시 여십시오.

## 진도를 iCloud에 저장하기

진도는 기기 안(브라우저 저장소)에 자동 저장됩니다. 기기를 바꾸거나 앱을 지우면 기기 안의 진도는 사라집니다. 주기적으로 iCloud Drive에 진도 파일을 저장하십시오.

먼저 설정 > Apple 계정 > iCloud에서 iCloud Drive를 켜십시오. 파일 앱의 iCloud Drive에 `JLPT 한자 진도` 폴더를 만들어 두면 찾기 쉽습니다.

### 저장

1. 사이드바 "설정"에서 `☁ iCloud에 저장`을 누르십시오.
2. 공유 화면에서 "파일에 저장"을 고르십시오.
3. iCloud Drive > `JLPT 한자 진도` 폴더를 고르고 저장하십시오.

파일 이름은 `jlpt-hanja-progress-YYYYMMDD.json`입니다. 버튼 아래에 "마지막 저장: N일 전"이 표시됩니다. 7일이 지나면 이 문구가 주황색으로 바뀝니다. 공유 화면을 지원하지 않는 브라우저(데스크톱 Chrome 등)에서는 파일을 내려받습니다.

### 불러오기

1. 사이드바 "설정"에서 `☁ iCloud에서 불러오기`를 누르십시오.
2. 파일 선택 화면에서 iCloud Drive > `JLPT 한자 진도` 폴더의 진도 파일을 고르십시오.

불러온 진도는 지금 진도와 병합합니다. 토리파 단계와 퀴즈 점수는 더 높은 값을 남깁니다. 복습 큐는 없는 단어만 더합니다. 모의 시험 기록은 시각 기준으로 합칩니다.

### Safari에서 쓰던 진도를 홈 화면 앱으로 옮기기

1. Safari로 주소를 열고 `☁ iCloud에 저장`으로 진도 파일을 저장하십시오.
2. 홈 화면에 앱을 추가하십시오.
3. 홈 화면 앱에서 `☁ iCloud에서 불러오기`로 1번의 파일을 고르십시오.

### 주의

- 웹 앱은 iCloud에 자동으로 저장할 수 없습니다. 저장할 때마다 "파일에 저장"을 직접 고르십시오.
- 홈 화면 아이콘을 지우면 그 앱의 진도도 지워집니다. 지우기 전에 진도 파일을 저장하십시오.
- 진도 파일에는 마지막 저장 시각을 넣지 않습니다. 이 시각은 기기마다 따로 기록합니다.

## 로컬에서 실행

`index.html`을 브라우저에서 바로 열면 됩니다. (데이터가 `data/hanja.js`에 포함되어 별도 서버가 필요 없습니다.)

서버로 띄우고 싶으면:

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

## GitHub Pages 배포와 접속 URL

이 폴더에서 아래 명령으로 저장소를 만들고 push 합니다.

```bash
cd /Users/digit82/repo/jlpt-hanja
rm -rf .git          # 준비 과정에서 생긴 빈 git 폴더 정리 (있을 때만)
git init
git add -A
git commit -m "JLPT 상용한자 2136 학습 웹앱"
git branch -M main
git remote add origin https://github.com/<사용자명>/jlpt-hanja.git
git push -u origin main
```

그다음 GitHub 저장소에서 Pages를 켭니다.

배포할 때마다 push 전에 버전을 올리십시오. 이 스크립트는 `index.html`의 `?v=` 값과 `sw.js`의 `VERSION`을 함께 바꿉니다.

```bash
scripts/bump-version.sh
node --test tests/   # 버전 일치, 매니페스트, 서비스 워커 테스트
```

- **방법 A (브랜치 배포)**: 저장소 **Settings → Pages → Source** 를 `Deploy from a branch`, Branch 를 `main` / `/(root)` 로 지정 후 저장.

### 접속 주소(URL)

배포가 끝나면 아래 주소로 접속합니다. (1~2분 소요)

```
https://<사용자명>.github.io/jlpt-hanja/
```

- 예: 사용자명이 `hong` 이면 → `https://hong.github.io/jlpt-hanja/`
- 저장소 이름을 다르게 만들었다면 `jlpt-hanja` 자리에 그 이름을 넣으세요.
- 실제 주소는 저장소 **Settings → Pages** 상단에도 표시됩니다.
